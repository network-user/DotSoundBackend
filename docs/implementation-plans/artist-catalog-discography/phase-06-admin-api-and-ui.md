# Phase 6 из 8 — Admin: API каталога и UI редактора

## Общий контекст задачи (вся цепочка 1–8)

Синк и публичное чтение уже есть (этапы 3–5). Этот этап даёт **операторам** ручное управление каталогом и **триггеры resync** на уже реализованные Taskiq-задачи (этап 3). Не заменяет движок синка — только вызывает его и правит БД через сервисы.

Подробная матрица: [README.md](README.md).

## Роль этого этапа

**Этап 6 из 8.** **Admin HTTP + admin UI:** CRUD релизов и позиций треков, поиск треков, reorder, POST resync; поля для ручного ввода `soundcloud_user_id`/permalink при необходимости.

## Границы (анти-конфликты)


| Делает этот этап                                                                  | Не делает                                                                                                  |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `api/v1/admin/...`, `require_admin_session`, интеграция с `AdminService` patterns | Переписывание ядра `artist_catalog_sync_service` без согласования — только вызовы и мелкие фиксы контракта |
| UI в `frontend/src/admin/`                                                        | Изменение публичного mini app UX (этап 5), кроме общих переиспользуемых компонентов по необходимости       |
| Триггер Taskiq из роутов                                                          | Не дублировать бизнес-импорт треков в роуте — только делегирование в сервис этапа 3                        |


**Prerequisites:** этапы 3–5 смержены (есть что триггерить и показывать).

**Выход для этапа 7:** админ может управлять каталогом; остаётся ужесточить лимиты и тесты.

---

## Цель

Админские endpoint’ы: CRUD релизов и позиций треков, поиск треков (reuse admin list), POST resync всего каталога и одного релиза. UI: экран/drawer у артиста — редактор каталога, DnD порядка, кнопки resync.

## Что делать

- Роуты под `api/v1/admin/`, `require_admin_session`, rate limits как у соседних admin роутов.
- Расширение `ArtistsRoute.tsx` или отдельный маршрут админки.
- Поля для ручного ввода `soundcloud_user_id` / permalink при необходимости.

## Критерии готовности

- Админ может вручную собрать релиз и запустить resync без ошибок 500.
