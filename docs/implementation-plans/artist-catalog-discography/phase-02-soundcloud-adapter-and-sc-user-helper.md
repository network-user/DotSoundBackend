# Phase 2 из 8 — SoundCloud: альбомы и хелпер SC user id

## Общий контекст задачи (вся цепочка 1–8)

Нужно реализовать **каталог релизов артиста** в DotSound: альбомы/EP/синглы с обложками и упорядоченными треками. Автосинхронизация с **SoundCloud** использует сохранённый `**artists.soundcloud_user_id`** и `GET …/users/{soundcloud_user_id}/albums`. Треки подтягиваются через `**import_or_get_track`**, связь через `**TrackArtist**`, таблицы каталога создаются в этапе 1. Mini app и админка — поздние этапы.

Подробная матрица: [README.md](README.md).

## Роль этого этапа

**Этап 2 из 8.** Дать **транспортный слой** к SoundCloud: методы получения списка альбомов пользователя и догрузки плейлиста; плюс **хелпер** записи `soundcloud_user_id`/`permalink` на сущность `Artist` по правилам конфликтов. Это фундамент для оркестратора синка (этап 3), но без заполнения каталога целиком.

## Границы (анти-конфликты)


| Делает этот этап                                                                                                 | Не делает                                                                                                              |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Расширение `SoundCloudService`: пагинация альбомов, resolve полного плейлиста при stub-треках; `soundcloud_slot` | Полный пайплайн синка в БД, Taskiq (этап 3)                                                                            |
| `ensure_soundcloud_ids_for_artist(...)` — запись на `Artist`                                                     | Вызов этого хелпера из массового синка можно добавить здесь только как экспорт; основная массовая оркестрация — этап 3 |

**Prerequisites:** этап 1 смержен (колонки `soundcloud_user_id` существуют).

**Выход для этапа 3:** стабильные методы API SC + хелпер id, которые синк-сервис импортирует и вызывает.

## Цель

Расширить `SoundCloudService`: пагинация `GET .../users/{soundcloud_user_id}/albums`, догрузка полного плейлиста при stub-треках. Добавить сервисный хелпер `ensure_soundcloud_ids_for_artist(artist_id, sc_user_id, permalink?)` с политикой конфликтов из плана.

## Что делать

- Новые методы в `app/services/soundcloud_service.py`, слот `soundcloud_slot`, прокси как у остальных методов.
- Хелпер записи `soundcloud_user_id` / permalink на `Artist` (через repository/service; без SQL в роутерах).
- Юнит-тесты с моками httpx по возможности.

## Критерии готовности

- Вызов альбомов по numeric SC user id работает в изоляции (тест или ручная проверка с `SC_CLIENT_ID`).
- Хелпер идемпотентен при совпадающем id; при конфликте — лог + без тихой перезаписи.
