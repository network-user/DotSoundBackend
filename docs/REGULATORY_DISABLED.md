# DotSound — Реестр временно отключённых модулей

Версия: **v1** (2026-05-10)

Этот файл — единственный источник истины по тому, **что и почему**
отключено в коде маркером `[REGULATORY-DISABLED v1]`. Код не удалён,
а закомментирован, чтобы его можно было вернуть после устранения
блокирующего регуляторного триггера.

## Триггер: ст. 10.1 149-ФЗ (организатор распространения информации)

Любой публичный сервис, через который пользователи обмениваются
**электронными сообщениями**, попадает под обязанности организатора
распространения информации (ОРИ):

- регистрация в реестре ОРИ Роскомнадзора;
- хранение метаданных переписки 1 год и содержимого 6 мес. на
  территории РФ;
- предоставление по запросу ФСБ ключей дешифровки (СОРМ).

Для физического лица без ИП/ООО эти обязанности **технически
неисполнимы** (нет инфраструктуры для СОРМ, нет процедуры
взаимодействия с ФСБ). Поэтому до оформления юрлица проект **не
предоставляет** функций обмена сообщениями между пользователями.

Авторская позиция оператора (Звягинцев Р. Н.) и общая стратегия —
см. `LEGAL.md`. Технический план — `.claude/plans/lucky-stargazing-badger.md`.

## Условия восстановления модулей

1. Зарегистрировать ИП или ООО в РФ (оператор перестаёт быть
   физлицом).
2. Подать заявление о включении в реестр ОРИ.
3. Развернуть инфраструктуру СОРМ либо заключить договор с
   уполномоченным провайдером.
4. Обновить Privacy Policy: добавить категорию ПДн «содержимое
   переписки», основания и сроки хранения.
5. Снять маркеры `[REGULATORY-DISABLED v1]` в перечисленных ниже
   файлах и инкрементировать версию пакета (`v2`).

## Что НЕ отключено (и почему)

- **`app/api/v1/blocks.py`** — односторонняя блокировка пользователя
  (скрытие из видимости). Не является обменом сообщениями, не
  триггерит ОРИ.
- **`app/api/v1/notifications.py`** — push-уведомления о лайках,
  подписках, jobs. Это server-to-user информирование, не
  peer-to-peer.
- **WS-канал `/ws` (общий)** — оставлен для real-time presence,
  job-status и notifications. Чат-обмен на нём отключён.
- **`GET /users/{target_id}/presence`** — общий статус пользователя
  (онлайн/оффлайн), не сообщение.
