# DotSound — Hosting & Localization

Версия: public-safe showcase draft.

Этот документ фиксирует общие требования к размещению инфраструктуры и
локализации персональных данных. Он намеренно не раскрывает конкретного
оператора, хостинг-провайдера, тариф, регион аккаунта или внутренние
доказательные артефакты.

## Общие требования

- Production-инфраструктура должна размещаться в юрисдикции,
  соответствующей требованиям применимого законодательства о
  персональных данных.
- Базы данных, объектное хранилище, кеши, очереди и бэкапы должны
  размещаться и обрабатываться согласно утверждённой privacy policy.
- Внешние subprocessors и cross-border transfers должны быть отдельно
  раскрыты в privacy policy и пользовательском соглашении.

## Компоненты

| Компонент | Назначение | Что хранит |
|---|---|---|
| PostgreSQL | Основная БД | Пользователи, треки, плейлисты, журналы, метаданные |
| MinIO / S3 | Объектное хранилище | Аудио, обложки, аватары, видео |
| Redis | Кеш, очереди, realtime | Сессии, дедупликация, очередь задач |
| Elasticsearch | Поиск, если включён | Индексы треков и артистов |
| Backend | API и веб-доставка | Runtime state |
| Worker | Фоновые задачи | Runtime state |

## Before Public Launch

- Зафиксировать реального оператора и legal/privacy contact вне
  публичного showcase-документа.
- Проверить provider contracts и регион размещения.
- Проверить backup retention и место хранения резервных копий.
- Проверить subprocessors и отключить любые нераскрытые внешние
  processing tiers.
- Хранить доказательные артефакты у оператора вне публичного
  репозитория.
