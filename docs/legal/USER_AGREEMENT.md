# Пользовательское соглашение DotSound

Версия: 1.0 (2026-05-10)

## 1. Стороны и статус сервиса

1. Сервис DotSound (далее — «Сервис») администрируется физическим
   лицом **Звягинцевым Робертом Николаевичем** (далее — «Оператор»),
   контактный адрес для юридических обращений: `legal@dotsound.app`.
2. Сервис является **некоммерческим личным проектом** Оператора:
   платежи, подписки, донаты внутри Сервиса не принимаются, реклама
   не размещается. Цель — портфолио и личный бренд автора.
3. Оператор является **информационным посредником** в значении
   ст. 1253.1 Гражданского кодекса РФ. Музыкальный и иной контент
   размещается пользователями (UGC); Сервис не выступает
   правообладателем загруженных материалов и не подтверждает наличие
   у пользователей соответствующих прав.
4. Доступ к Сервису ограничен лицами, достигшими **18 лет**
   (см. раздел 9).

## 2. Категории контента

В Сервисе могут присутствовать:

- пользовательский контент (UGC), загруженный пользователями;
- внешние треки, для которых Сервис показывает метаданные и
  ссылку на исходный источник (категория `external_reference`).

Лицензированный контент по договорам с правообладателями в текущей
версии Сервиса не присутствует.

## 3. Гарантии пользователя

Пользователь подтверждает и гарантирует, что:

1. обладает необходимыми правами на загружаемый контент либо имеет
   надлежащее разрешение правообладателя;
2. не загружает материалы, нарушающие авторские, смежные,
   персональные, имущественные или иные права третьих лиц;
3. не использует Сервис для распространения запрещённых
   законодательством РФ материалов;
4. достиг возраста 18 лет.

## 4. Лицензия на пользовательский контент

Пользователь предоставляет Оператору неисключительную безвозмездную
лицензию, необходимую для:

- хранения загруженного контента;
- технической обработки и транскодирования;
- показа и предоставления доступа в рамках Сервиса;
- модерации, ограничения доступа и удаления при наличии законных
  оснований либо обоснованной жалобы.

Лицензия действует только в объёме, необходимом для работы Сервиса
и исполнения требований закона; вознаграждение по ней не
выплачивается, поскольку Сервис некоммерческий.

## 5. Ограничения для пользователя

Пользователю запрещается:

- загружать чужие произведения без прав или разрешения
  правообладателя;
- обходить ограничения правообладателей и внешних источников;
- использовать Сервис для копирования, архивирования или
  несанкционированного распространения контента;
- выдавать внешний контент за собственный;
- использовать Сервис для деятельности, нарушающей законодательство
  РФ.

## 6. Внешние источники

1. Для внешних треков Оператор может хранить метаданные, имя
   источника (`source_name`) и прямую ссылку на оригинальный
   материал (`source_page_url`).
2. Оператор не позиционирует себя как правообладатель внешнего
   контента.
3. Доступность внешнего трека зависит от исходного источника и его
   правил; Оператор вправе в любой момент перевести воспроизведение
   внешних треков в режим открытия по ссылке без проигрывания внутри
   Сервиса.

## 7. Жалобы пользователей и уведомления правообладателей

1. Любой пользователь может направить жалобу на контент через
   функцию жалоб в интерфейсе Сервиса.
2. Уведомления правообладателей принимаются на адрес
   `legal@dotsound.app` либо через специальную страницу
   `/legal/rightsholders`. Порядок и обязательные сведения —
   см. `COPYRIGHT_POLICY.md`.
3. Оператор рассматривает обоснованные уведомления и принимает меры
   (скрытие, удаление, ограничение доступа) **в срок не более
   5 (пяти) рабочих дней** с момента получения уведомления,
   содержащего сведения, необходимые для идентификации произведения
   и заявителя.
4. Оператор вправе временно скрыть или удалить контент при получении
   жалобы или при выявлении признаков нарушения правил Сервиса до
   завершения рассмотрения.
5. Систематические нарушения правил пользователем могут повлечь
   ограничение доступа к аккаунту.

1. Пользователь несёт ответственность за законность загружаемого им

## 9. Возрастное ограничение

Сервис предназначен для пользователей, достигших **18 лет**.
Контент, размещаемый пользователями, может содержать ненормативную
лексику и иные материалы, не предназначенные для несовершеннолетних
(ст. 5 436-ФЗ). Подтверждение возраста выполняется при первом входе
в приложение.

Любые предложения по оплате услуг от имени Сервиса либо рекламные
интеграции, размещённые третьими лицами, должны рассматриваться как
несанкционированные.
