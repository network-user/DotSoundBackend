# Чек-лист проверки внешних источников

Статус: internal only

Версия: 2026-04-15

Этот документ нужен для проверки внешних источников до публичного
запуска current MVP с `third_party_stream`.

## Для каждого внешнего источника проверить

### 1. Contract / Terms

- Разрешает ли Terms/API использование контента в стороннем
  приложении?
- Разрешает ли источник собственный playback внутри стороннего UI?
- Допускается ли `stream URL`-based playback без официального embed?
- Есть ли ограничения на:
  - alternative on-demand service
  - aggregation into a separate catalog
  - monetization
  - caching
  - offline access
  - copying metadata / covers / user content

### 2. Technical model

- Использует ли DotSound только link-out?
- Использует ли официальный embed/player источника?
- Использует ли собственный player поверх stream URL источника?
- Создаются ли локальные копии аудио, кэш, HLS или офлайн-данные?

### 3. Attribution

- Показывается ли название источника?
- Есть ли ссылка на оригинальный track page?
- Есть ли риск, что пользователь воспримет внешний трек как
  собственный контент DotSound?

### 4. Rights / takedown

- Может ли DotSound быстро скрыть карточку внешнего трека и доступ к
  информации, необходимой для его получения?
- Понятно ли правообладателю, как подать уведомление?

## Текущий приоритет

До публичного запуска проверить как минимум:

- `SoundCloud`
- любой другой внешний источник, если он будет подключен позже

## MVP-правило

Если Terms источника явно не допускают current model, нельзя
масштабировать интеграцию только потому, что технически она работает.
